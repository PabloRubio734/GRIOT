# GRIOT — Notas de entrega (versión propuesta v1.0.0)

**Proyecto:** Personal Project del IB MYP de Manolo Rubio Martín  
**Producto:** GRIOT, mentor académico con inteligencia artificial  
**Aplicación:** https://griot-coral.vercel.app  
**Código:** https://github.com/PabloRubio734/GRIOT

## Contenido de la primera entrega pública

- Aplicación web desarrollada con Next.js, React y TypeScript.
- Tres perfiles de apoyo: Comprensión, Organización y Profundización.
- Ciclo pedagógico: Diagnosticar → Explicar → Comprobar → Adaptar.
- Integración con Anthropic Claude desde el servidor.
- Orientaciones de integridad académica y modo de demostración diferenciado.
- Pruebas técnicas con un simulador de la API y automatización de interfaz.

## Evidencias y limitaciones

- Los tests con API simulada no equivalen a estudios reales de utilidad o usabilidad con estudiantes.
- El historial público de GitHub comienza con la publicación del proyecto; no documenta las fases anteriores.
- Los límites de solicitudes actuales son **en memoria**, por lo que no garantizan un máximo global en Vercel ni un tope de gasto. Antes de una difusión pública amplia se recomienda añadir un limitador compartido y controles de presupuesto.
- Las respuestas de IA pueden contener errores. Las conversaciones de la pestaña no constituyen un registro permanente.
